### receita_por_pagamento
> Qual o valor total pago por tipo de pagamento?

```sql
WITH delivered_orders AS (
    SELECT order_id
    FROM orders
    WHERE order_status = 'delivered'
)
SELECT
    op.payment_type,
    round(SUM(op.payment_value), 2) AS total_pago
FROM order_payments AS op
JOIN delivered_orders AS d
    ON op.order_id = d.order_id
GROUP BY op.payment_type
ORDER BY total_pago DESC
LIMIT 20
```

### faturamento_por_ano
> Qual o faturamento (soma dos preços dos itens) de pedidos entregues em cada ano?

```sql
WITH delivered_orders AS (
    SELECT
        order_id,
        EXTRACT(year FROM order_delivered_customer_date) AS ano_entrega
    FROM orders
    WHERE order_status = 'delivered'
      AND order_delivered_customer_date IS NOT NULL
)
SELECT
    ano_entrega AS ano,
    round(SUM(oi.price), 2) AS faturamento
FROM delivered_orders d
JOIN order_items oi USING (order_id)
GROUP BY ano
ORDER BY ano
```
