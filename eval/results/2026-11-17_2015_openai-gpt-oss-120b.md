### frete_medio_item
> Qual o valor médio do frete por item vendido?

```sql
SELECT 
    ROUND(AVG(oi.freight_value), 2) AS frete_medio
FROM 
    order_items AS oi
JOIN 
    orders AS o
    ON oi.order_id = o.order_id
WHERE 
    o.order_status = 'delivered'
```

### receita_por_pagamento
> Qual o valor total pago por tipo de pagamento?

```sql
WITH delivered_orders AS (
    SELECT order_id
    FROM orders
    WHERE order_status = 'delivered'
)

SELECT
    op.payment_type      AS tipo_pagamento,
    round(SUM(op.payment_value), 2) AS valor_total_pago
FROM order_payments AS op
JOIN delivered_orders AS d
    ON op.order_id = d.order_id
GROUP BY op.payment_type
ORDER BY valor_total_pago DESC
```

### faturamento_por_ano
> Qual o faturamento (soma dos preços dos itens) de pedidos entregues em cada ano?

```sql
SELECT 
    EXTRACT(year FROM o.order_delivered_customer_date) AS ano,
    ROUND(SUM(oi.price), 2) AS faturamento_anual
FROM orders AS o
JOIN order_items AS oi
    ON oi.order_id = o.order_id
WHERE o.order_status = 'delivered'
  AND o.order_delivered_customer_date IS NOT NULL
GROUP BY ano
ORDER BY ano
```
